# The licenses of FreeBSD's packages, by the names FreeBSD's ports give
# them (LICENSE in a port's Makefile, licenses in a package's manifest
# and in the catalogue; Mk/bsd.licenses.db.mk of the ports tree defines
# the common ones), each with what build.sh does about a package under
# it:
#
#   source   the license asks whoever passes the program on for its
#            source, or to say where the source is: the package goes
#            out with its source, in packages-source.tar (README.md,
#            Licenses and sources)
#   -        it asks for no source; the package carries the license in
#            /usr/local/share/licenses, and nothing is added
#
# A package under several licenses goes out with its source when one of
# them is of the first kind, whether it is under all of them or under
# any. build.sh stops at a package with a license that has no line
# here, and at one that names no license: somebody reads the license
# then and adds the line. That is why NONE has no line, and why the
# licenses that restrict passing a package on itself have none
# (CC-BY-NC-*, CC-BY-ND-*). A GNU license, MPL, CDDL, EPL or EUPL with
# a "-" is refused.
